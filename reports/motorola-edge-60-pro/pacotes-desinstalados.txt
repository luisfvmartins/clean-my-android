# Pacotes Desinstalados para o Usuário 0 no Motorola Edge 60 Pro (XT2507-1)
#
# NOTA TÉCNICA SOBRE DESINSTALAÇÃO NO ANDROID (SEM ROOT):
# 1. Aplicativos de terceiros (/data/app): a desinstalação via "pm uninstall --user 0" remove completamente o APK e os dados do usuário.
# 2. Pacotes de sistema (/system, /product): o comando "pm uninstall -k --user 0" marca o pacote como "installed=false" para o Usuário 0 e limpa seus dados/cache em /data, mas o APK original de fábrica permanece preservado na partição de sistema (somente leitura). Não há exclusão física da partição do sistema.
# 3. Atualizações de apps de sistema: quando um app de sistema é atualizado pela Play Store, a nova versão fica gravada em /data/app. O comando "pm uninstall <pacote>" remove essa atualização e reverte o aplicativo à versão base de fábrica.
# 4. Mensuração de armazenamento: o ganho total de espaço livre observado na partição /data durante a sessão foi de aproximadamente 4 GB em termos agregados (de 193 GB para ~197 GB). No entanto, o ganho individual por pacote NÃO foi mensurado separadamente. Valores individuais não devem ser somados.
